# UI module

Compound has two UI APIs. Choose the guide matching the version used by your mod.

- [Composable UI for Compound 2.0](Composable-UI): screens built with composition scopes, state, layouts, controls, and animations. Introduced by [PR #4](https://github.com/TridentMC/Compound/pull/4), targeting Minecraft 26.3 and NeoForge 26.3.0.26-beta. Consult the PR for merge status; a branch version does not imply a published Maven release.
- [Legacy UI for Compound 1.x](Legacy-UI): the Element/Layout API retained in the 1.18.0 Minecraft 26.3 baseline.

Compound is a library included by your mod. For a working demo, see [Molecule](https://github.com/TridentMC/Molecule/tree/codex/composable-ui-demo-26.3).
